01

Prepare the runtime

Use Node.js 24 or later and a funded model API account. Windows may need Git Bash. The six local labs generate their own short-lived classroom credentials. Only the GitHub mode needs a separate real token.

node --version
npm --version
02

Install and create your .env file

From presentations, install dependencies and preserve an existing .env. Enter your keys locally. Shell values take precedence over the optional startup env file.

cd .\agent-sdk\lesson25-mcp-auth-errors
npm ci
if (!(Test-Path .env)) { Copy-Item .env.example .env }
notepad .env
03

Start the web application

Open the printed URL and keep the terminal running. The app starts its own local teaching services and the SDK starts the stdio process. No separate production provider is needed for the local labs.

npm start
# http://127.0.0.1:3125
04

Compare env, headers and project placeholders

Run the first three modes. Inspect redacted configuration and successful authenticated tool results. Project config contains placeholders while the runtime supplies a generated value.

npm run sample:env -- stdio-env
npm run sample:env -- http-header
npm run sample:env -- json-expansion
05

Complete the classroom OAuth flow in the browser

Choose OAuth mode in the web app, click Run, then Approve classroom access in the embedded consent screen. The real local code exchange validates state and PKCE before the SDK connects. The CLI also emits the local consent URL; open it in your browser to approve.

npm run sample:env -- oauth-handoff
06

Detect failure, recover and read GitHub issues

Run bad-token health and reconnect, then GitHub with your local PAT. GitHub is limited to list_issues for three public anthropics/claude-code issues. No writes or comments are allowed.

npm run sample:env -- bad-token-health
npm run sample:env -- reconnect
npm run sample:env -- github
npm test

Your .env configuration

GITHUB_MCP_TOKEN=your_read_only_token
ANTHROPIC_API_KEY=your_api_key
CLAUDE_MODEL=claude-sonnet-4-6
PORT=3125
# Optional on Windows: CLAUDE_CODE_GIT_BASH_PATH=C:/Program Files/Git/bin/bash.exe

Keep the actual key private. No Managed Agents agent ID or environment ID is required. No duplicate snapshot is included.

Troubleshooting

Use the URL printed by startup. If another app occupies the port, change PORT and restart. If API credit is unavailable, add credit to the account used by this key. Authentication and connection failures remain visible; no saved data replaces a failed call. Approve classroom OAuth in the browser when that mode is selected. GitHub requires GITHUB_MCP_TOKEN and internet access.

Configure GITHUB_MCP_TOKEN

  1. Open GitHub’s fine-grained token page.
  2. Name the token, choose an expiration and select Public repositories (read-only).
  3. Generate the token and save it locally as GITHUB_MCP_TOKEN in .env.
  4. Restart the application. Keep the token out of chat and screenshots.

This example reads public issues from anthropics/claude-code and needs no private-repository or write permissions.
